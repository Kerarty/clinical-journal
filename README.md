# История болезни № 001

Личный сайт-журнал для одного единственного читателя. Оформлен как винтажный
медицинский журнал: история болезни, диагноз, назначение и личное письмо.
Никаких корпоративных лендингов — только бумага, чернила и немного любви.

## Что внутри

- **Хиро** — глянцевое 3D-сердце (Three.js), которое можно повращать, живая
  кардиограмма на canvas и счётчики дней, тикающие в реальном времени.
- **Анамнез** — таймлайн истории с фотографиями-полароидами.
- **Диагноз** — карта пациента с печатью «подтверждено».
- **Назначение** — рецептурный бланк курса пожизненного.
- **Снимки** — архив наблюдений с лайтбоксом.
- **Прогноз** — личное письмо и кнопка «принять диагноз» с дождём из сердечек.

## Как это собрано

- Чистый HTML/CSS/JS, никаких фреймворков. Три.js подключён через importmap
  с CDN.
- 3D-сердце — [BodyParts3D](https://lifesciencedb.jp/bp3d/) (CC BY 4.0),
  загружается через GLTFLoader и одевается в стеклянный материал.
- Цветы на сердце — [Poly Pizza](https://poly.pizza) (CC0, автор Isa Lousberg),
  размещаются на поверхности меша raycast'ами.
- Кардиограмма — своя отрисовка на canvas: узор стационарен на ленте, движется
  только пишущая головка, частота синхронизирована с пульсом сердца.
- Сборка: `python build.py` складывает хиро-фрагмент и секции в `index.html`.
- Деплой: GitHub Pages из ветки `main`.

## Приватность

Сайт помечен `noindex`, `robots.txt` закрывает индексацию. Фотографии в репозитории
принадлежат героям этой истории и публикуются только для одного читателя.
